================================================================================
                        GIT WORKFLOW OVERVIEW
================================================================================

1. CREATE FEATURE (from develop branch)
   git checkout develop
   git checkout -b feature/user-authentication

2. WORK & COMMIT
   # Make changes
   git add .
   git commit -m "feat: add user login"
   git push -u origin feature/user-authentication

3. CREATE PULL REQUEST
   • Go to GitHub
   • Create PR: feature/user-authentication → develop
   • Request review
   • Address comments

4. MERGE TO DEVELOP
   • PR approved
   • Merge via GitHub UI (or command line)
   • Delete feature branch

5. RELEASE (when ready)
   git checkout -b release/1.0.0
   # Update version numbers
   git commit -m "chore(release): bump to 1.0.0"
   # PR release → main
   # Merge & tag: v1.0.0

See docs/GITFLOW.md for detailed workflow guide!
