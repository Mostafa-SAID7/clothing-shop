# Contributing to Clothing Shop

We love your input! We want to make contributing to Clothing Shop as easy and transparent as possible, whether it's:

- Reporting a bug
- Discussing the current state of the code
- Submitting a fix
- Proposing new features
- Becoming a maintainer

## Development Process

We use GitHub to host code, to track issues and feature requests, as well as accept pull requests.

### Getting Started

1. Fork the repository and clone it locally
2. Navigate to the frontend directory: `cd frontend`
3. Install dependencies: `npm install`
4. Create a new branch for your feature: `git checkout -b feature/amazing-feature`
5. Start the dev server: `npm run dev`

### Code Style

- Use TypeScript for type safety
- Follow the existing code style
- Run `npm run typecheck` before committing
- Keep components modular and reusable

### Making Changes

1. Make your changes in the frontend directory
2. Test your changes thoroughly
3. Ensure TypeScript type checking passes: `npm run typecheck`
4. Commit your changes with clear, descriptive messages

### Submitting Changes

1. Push your changes to your fork
2. Submit a pull request to the main repository
3. Ensure CI/CD checks pass
4. Wait for code review

## Pull Request Process

1. Update the documentation with details of changes
2. Update the README.md with any new features or dependencies
3. Ensure your PR description clearly describes the problem and solution
4. Link any related issues in the PR description

## Reporting Bugs

When reporting a bug, please include:

- A clear and descriptive title
- A detailed description of the behavior
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Browser/Node version information
- Any relevant code snippets

## Feature Requests

Feature requests are always welcome! Please provide:

- A clear and descriptive title
- A detailed description of the proposed feature
- Use cases and benefits
- Possible implementation approaches (optional)

## Code of Conduct

### Our Pledge

In the interest of fostering an open and welcoming environment, we as contributors and maintainers pledge to making participation in our project and our community a harassment-free experience for everyone.

### Our Standards

Examples of behavior that contributes to creating a positive environment include:

- Using welcoming and inclusive language
- Being respectful of differing opinions, viewpoints, and experiences
- Gracefully accepting constructive criticism
- Focusing on what is best for the community
- Showing empathy towards other community members

### Enforcement

Violations of the Code of Conduct may result in temporary or permanent bans from the project.

## Questions?

Feel free to open an issue with the question label or reach out to the maintainers.

Thank you for contributing! 🎉
