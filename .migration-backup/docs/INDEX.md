## 📝 Quick Reference

### Essential Commands

```bash
# Setup
pnpm install
cp .env.example .env.local
cd lib/db && pnpm run push && cd ../..
cd lib/api-spec && pnpm run codegen && cd ../..

# Development
cd api-server && pnpm run dev
cd style-haven && pnpm run dev

# Type checking
pnpm run typecheck:all

# Production
cd api-server && pnpm run build && pnpm run start
cd style-haven && pnpm run build && pnpm run serve
```
